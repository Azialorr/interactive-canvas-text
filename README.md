# Interactive Canvas Text

An interactive HTML Canvas project that allows users to move text using their keyboard.

## Features

- Moves text using the arrow keys
- Keeps the text within the canvas boundaries
- Changes the text to a random color when it moves
- Uses keyboard event handling for user interaction

## Technologies Used

- HTML
- JavaScript
- HTML Canvas API

## What I Learned

This project helped me practice working with the HTML Canvas API, JavaScript event listeners, keyboard input, conditional statements, and canvas coordinates.
